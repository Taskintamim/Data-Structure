🔄 Sorting Algorithms
Bubble Sort

Repeatedly swaps adjacent elements.

Example
5 4 3 2 1

Pass 1
4 3 2 1 5

Pass 2
3 2 1 4 5

Pass 3
2 1 3 4 5

Pass 4
1 2 3 4 5
Complexity
Best	Average	Worst
O(n)	O(n²)	O(n²)
Selection Sort

Find minimum element and place it correctly.

Complexity
Best	Average	Worst
O(n²)	O(n²)	O(n²)
